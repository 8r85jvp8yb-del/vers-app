# Shutdesk – three Reels directions (1080×1920, 30 fps, silent)

Source of every fact and label: the App Store listing (id6815319699, nb) – description, the five
screenshots and the app icon. Photos are cropped from those screenshots. App screens are rebuilt
flat in HTML from the screenshots' own labels (no invented buttons or text).

## A · «Mens kampen pågår» (24 s)
Device: one photographer's real task, start to finish. Form: object-to-object chain.
Kampen pågår fortsatt → shutter → «Fra kamera til redaksjon. Uten laptop.» → the photo is carried
into the phone («Rett til iPhone. Over Wi‑Fi.») → MEMO confirms #33 Andreas Nibe, #24 Sigurd Rosted,
caption types in («Si navnet.») → «Send bildet.» → zoom through Send → Mini Desk receives it
(«Levert mens kampen pågår.») → lockup, «Hele desken. Rett i lomma.», App Store CTA.
Look: flat brand cobalt #1b4fb0, white Barlow Condensed 900 italic, sky #8ed8ff accent word.

## B · «Hele desken. Rett i lomma.» (21.5 s)
Device: type carries the argument. Form: cut on a 120 BPM grid (one panel per 4 beats).
Hele desken. → Wi‑Fi. → #5 → MEMO. → IPTC. → FTP. → Mini Desk. → the phone's Automatikk switches
flip on the beat → «Rett i lomma.» → lockup, «Fra kamera til redaksjon. Uten laptop.», CTA.
Look: alternating ice #eef4fb / cobalt fields, giant italic words, one real UI piece per word.

## C · «Se nummeret.» (20 s) – recommended to post first
Device: the feature as the hook. Form: one pull-back zoom.
Frame 0 is the #5 jersey, ringed → «Finn spilleren.» → the camera pulls back 6.5× into the same
number inside Shutdesk → Draktanalyse «Fant 1 nummer i bildet» → two #5 candidates → you pick
Kevin Tshiembe (the name on the shirt) → «Du bekrefter.» → Send opens an iris → end card.
Look: near-black night, the photo fills the frame, sky ring as the only accent.

## What was checked
- `hyperframes check`: 0 errors on all three. Kept warnings: film_silent (see below), small UI type
  inside the phone (real UI scale; the line that matters is always repeated in a big title),
  B's caption card is on screen 1.4 s (texture in a beat montage, not meant to be read in full).
- Looked at: beat frames, both seams in A, the pull-back in C frame by frame, every panel in B.
- Not checked by eye: the full-speed playback feel on a phone.

## Sound
None. Music needs a HeyGen sign-in (free) and SFX need Openverse, both blocked in this
environment. For Reels, add a track from Instagram's own audio library when posting.

## Weakest shots / next steps
- A 0–1.4 s: the hook photo is a 1.8× upscale of a screenshot crop – soft on a big screen.
  A real full-res match photo would make the hook land harder.
- C 4.3–5.3 s: the phone sits with an empty lower screen for ~1 s before the analysis appears.
- All three would gain from a real screen recording of the app instead of rebuilt screens.
